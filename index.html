Fumibako 文箱

Markdown と画像のフォルダを、そのままノートアプリとして開きます。
データはフォルダの中のファイルだけ。この HTML は表示と編集をするだけです。

Google ドライブに置くと、PC とスマホで同じノートを開けます（https の URL で開いたとき）。
PC のフォルダは Chrome / Edge で使えます。保存は ⌘S、または自動保存。
